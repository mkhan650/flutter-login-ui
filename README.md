# Flutter Login UI 📱

A modern and responsive login screen built with Flutter and Dart.

## ✨ Features

* Clean and modern UI
* Responsive layout
* Email and password input fields
* Password visibility toggle
* Login button
* Forgot password option
* Create account option
* Mobile-friendly design

## 🛠️ Built With

* Flutter
* Dart

## 🚀 Getting Started

### Prerequisites

Make sure you have Flutter installed on your system.

### Installation

Clone the repository:

```bash
git clone https://github.com/mkhan650/flutter-login-ui.git
```

Open the project:

```bash
cd flutter-login-ui
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
